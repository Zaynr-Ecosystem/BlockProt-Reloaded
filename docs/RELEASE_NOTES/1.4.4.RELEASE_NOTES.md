# BlockProt Reloaded 1.4.4 Release Notes

Welcome to BlockProt Reloaded 1.4.4. This release organizes internal SQLite storage and state markers into a clean `data/` folder with automatic migration, adds an in-game release notes viewer with direct GitHub Release links across Paper Dialogs, chat, chest menus, and Bedrock forms, and expands anonymous bStats charts to measure configuration and feature adoption. It maintains full support for Minecraft 1.21.7 through 26.3 on Paper, Purpur, and Folia.

## Highlights

- **Organized `data/` Internal Storage**: moved `blockprot_usercache.sqlite` (to `data/usercache.sqlite`), `blockprot_audit.sqlite` (from `mysql/` to `data/audit.sqlite`), and internal root dot-files (`.edition`, `.first_start_done`, `.recommended_state.yml` into `data/state.yml`) while keeping human-editable configs clean in `plugins/BlockProtReloaded/`.
- **In-Game Changelog & GitHub Release Viewer**: `UpdateChecker` now captures release notes from GitHub Releases and surfaces clean formatted summaries alongside direct clickable links in `UpdateDialog`, chest admin menu updates, CLI `/bp update`, and Bedrock admin forms.
- **One-Time Post-Upgrade Admin Notice**: upgrades tracked in `data/state.yml` (`changelog.last_seen_version`) deliver a single clickable update summary notice on admin join without triggering on brand-new installations.
- **Expanded bStats Telemetry (`#31548`)**: added `ui_mode` (Dialogs, Menus, Menus + Dialogs, Commands), `recommended_setup` (usage tracking for `/bp recommended` vs. manual setup), and `feature_usage` (per-feature adoption bar chart).
- **Configuration Hygiene Audit**: verified all active configuration keys across `config.yml`, `blocks.yml`, `worlds.yml`, `integrations.yml`, and `mysql/mysql.yml` and corrected the `BLOCK_FAMILY_SYNTAX.md` documentation path reference in `config.yml`.

## Changelog

### Added

- `PluginDataLayout` centralized internal storage and startup migration helper (including SQLite `-wal` and `-shm` sidecars and empty `mysql/` directory cleanup when `mysql.yml` is absent).
- `ReleaseNotesFormatter` in `:common` for pure-Java Markdown-to-summary formatting, plus `UpdateChecker.installedRelease` tracking and `tagReleaseUrl` fallback links.
- Dedicated "Release Notes" view and inline highlights inside `UpdateDialog`, post-upgrade one-time admin join notice in `JoinEventListener`, chat summary delivery for chest/CLI updates, and an Updates & Release Notes form in `BedrockAdminMenuForm`.
- Three anonymous bStats charts: `UiModePieChart` (`ui_mode`), `RecommendedUsagePieChart` (`recommended_setup`), and `FeatureUsageBarChart` (`feature_usage`).
- Localized translation entries across English, Spanish, German, and French (`translations_en.yml`, `translations_es.yml`, `translations_de.yml`, `translations_fr.yml`).

### Changed

- Updated `BlockProt`, `AuditLogger`, `LegacyMigrationManager`, `RecommendedCommand`, `BackupTask`, and `EnvironmentDiagnostics` to read and write internal runtime files through `PluginDataLayout` under `data/`.
- `BackupTask.hasPriorData` now skips managed `data/usercache.sqlite` and `data/state.yml` on fresh installs while recognizing `data/audit.sqlite` as existing history.
- Moving `.recommended_state.yml` into `data/state.yml` avoids false file-watcher config reload triggers.
- Updated `docs/READ_MEs/ADMIN_GUIDE.md` and `docs/READ_MEs/VERSION_GUIDE.md` to document the new `data/` paths and automatic migration.

### Fixed

- Fixed broken relative `docs/BLOCK_FAMILY_SYNTAX.md` comment path in `spigot/src/main/resources/config.yml` to point to `docs/MODERN SYNTAX AND LEGACY/BLOCK_FAMILY_SYNTAX.md`.
- Hid raw release URLs in chat and `UpdateDialog` components behind clickable localized labels with hover hints, and omitted empty release-notes headers when notes are not published yet.
- Fixed `/bp user` dialog/inventory mode switching in `UserSettingsDialog`, `UserSettingsInventory`, `BedrockUserSettingsForm`, and `BlockProtInventory` so enabling or disabling Paper Dialogs preserves the parent origin and does not reopen chest menus when going back.
