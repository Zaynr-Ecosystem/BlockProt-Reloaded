# BlockProt Reloaded 1.4.2 Release Notes

Welcome to BlockProt Reloaded 1.4.2. This release adds custom permissions per friend, closes the remaining item and piston paths around protected blocks, and adds a paginated access log viewer with `/bp logs`. It keeps the same support range as the 1.4.0 line: Minecraft 1.21.7 through 26.3 on Paper, Purpur, and Folia.

> **Note on the version number:** the second hotfix of the 1.4.0 line was published as `1.4.1-hotfix.2`, but it should have been `1.4.0-hotfix.2`, because `1.4.1` was reserved for the next feature release. A published hotfix ranks above a plain release of the same number, so a plain `1.4.1` would never be seen as an update. This feature release is therefore numbered **1.4.2**, and version numbers continue normally from here.

## Highlights

- **Custom Friend Permissions**: friends can be set to the Custom level with four independent permissions: Open Container, Deposit Items, Withdraw Items, and Redstone Access. They are enforced when opening containers, moving items in and out, and using doors, trapdoors, and other redstone-controlled blocks.
- **Protection On Every Path**: hopper checks now cover both directions, so items can no longer be pulled out of or pushed into a protected block, hoppers can no longer feed items into protected vehicles, and pistons can no longer move protected blocks.
- **Access Logs**: `/bp logs [here|player <name>|<page>]` opens the paginated access audit log for a player, for the block you are looking at, or for recent entries, and the same views are available as Paper dialogs.
- **Region Protection Interoperability**: interactions cancelled or denied by another plugin, such as a region or claim protection plugin, are now respected.

## Changelog

### Added

- Custom permissions per friend: the Custom level grants Open Container, Deposit Items, Withdraw Items, and Redstone Access independently.
- The `/bp logs` command and Paper dialog views for the access audit log, with filters by player and by block location, and pagination.
- Hopper protection for protected vehicles.

### Changed

- Reworked configuration handling into smaller components and optimized lock lookups; existing `config.yml`, `blocks.yml`, and `worlds.yml` files are unchanged.
- Split the `/bp debug` diagnostics into domain suites, so reports are grouped by area.
- Moved startup migrations and repairs out of the main plugin class.

### Fixed

- Interactions cancelled or denied by another plugin are now respected instead of being processed further.
- Exceptions from file operations and tasks are now recorded through the plugin logger.

## Editions

BlockProt Reloaded covers Minecraft 1.21.7 and newer. BlockProt Reloaded Legacy (Minecraft 1.20.5 to 1.21.6) and BlockProt Legacy (Minecraft 1.18.2 to 1.20.4) are unchanged by this release. The [version guide](https://github.com/Zaynr-Ecosystem/BlockProt-Reloaded/blob/main/docs/READ_MEs/VERSION_GUIDE.md) explains which one to download and how to move between them.
