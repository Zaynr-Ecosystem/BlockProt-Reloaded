# BlockProt Reloaded 1.4.5 Release Notes

Welcome to BlockProt Reloaded 1.4.5. This release strengthens update visibility so admins know right away when a newer build is available, enables automatic update notifications for operators by default, ensures automatic ZIP backups run reliably on every plugin version update (including patch upgrades) and legacy `data/` migrations, and maintains full support for Minecraft 1.21.7 through 26.3 on Paper, Purpur, and Folia.

> **Important note for servers on `1.4.1-hotfix.2` or earlier:** Builds older than `1.4.2` still query the previous repository URL without following redirects, so they will not notify you about newer releases automatically. Please update manually to `1.4.5` from [GitHub Releases](https://github.com/Zaynr-Ecosystem/BlockProt-Reloaded/releases), [Modrinth](https://modrinth.com/plugin/blockprot-reloaded), [CurseForge](https://www.curseforge.com/minecraft/bukkit-plugins/blockprot-reloaded), or [Hangar](https://hangar.papermc.io/Zaynr-Ecosystem/BlockProt-Reloaded) to restore automatic update alerts and receive all recent security, Folia, backup, and UI fixes.

## Highlights

- **Proactive Update Alerts (`notify_op_of_updates: true`)**: Enabled operator join update notifications by default for new installations, updated translation copy across `en`/`es`/`de`/`fr` to highlight why updating matters even when only 1 build behind, and added a pending-update banner and highlighted Update button in `/bp admin` (both Paper Dialogs and Chest Inventory UIs).
- **Automatic Backup on Every Version Upgrade**: `BackupTask` now triggers on patch version changes (for example `1.4.4` to `1.4.5`) in addition to edition transitions, major.minor bumps, and `BEDev` builds, backing up your configuration files even when no `audit.sqlite` database exists yet.
- **Data Layout Migration Backup Trigger**: `BlockProt` now tracks when `PluginDataLayout.migrateAll(...)` relocates legacy databases or dot-files during `onLoad()`, ensuring a startup backup ZIP is created right alongside automatic storage migration.
- **Zero Noise on Fresh Servers**: brand-new installations without a prior version marker or migrated files continue skipping startup ZIP backups cleanly.

## Changelog

### Improved

- Enabled `notify_op_of_updates: true` by default in `config.yml` and `DefaultConfig.shouldNotifyOpOfUpdates()`. Existing server configs with `notify_op_of_updates: false` are never overwritten.
- Added `UpdateChecker.getAvailableUpdate(...)` and surfaced a visible outdated notice and highlighted update button inside `AdminMenuDialog` and `AdminMenuInventory` whenever a newer stable release is detected.
- Clarified update alert strings in `translations_en.yml`, `translations_es.yml`, `translations_de.yml`, and `translations_fr.yml` so admins see that even 1 build behind is worth updating.

### Fixed

- Added a prominent red console banner and clean plugin self-disable (`disablePlugin`) whenever any edition is started outside its supported Minecraft range (below or above), naming the matching edition (`BlockProt Legacy`, `BlockProt Reloaded Legacy`, or `BlockProt Reloaded`) and its direct Modrinth download URL while letting the server keep running normally.
- Preserved `dataLayoutMigrated` from `onLoad()` in `BlockProt` so `BackupTask` runs on `onEnable()` when internal SQLite or marker files were migrated out of root/`mysql/` into `data/`.
- Added `BackupTask.isVersionChanged`, `BackupTask.isStartupUpgradeOrMigration`, and `BackupTask.forStartupUpgrade` so patch upgrades archive existing configs (`config.yml`, `blocks.yml`, `worlds.yml`, `integrations.yml`, `lang/`, `data/`) without breaking `Transition.migration()` edition checks.

### Tests

- Added regression tests in `UnsupportedVersionBannerTest` covering mismatched edition and Minecraft version detection, recommended edition selection, Modrinth download links, and banner formatting across all three editions.

- Added regression tests in `BackupTaskEditionMarkerTest` covering patch upgrades (`1.4.4` to `1.4.5`), unchanged restarts, `data/` layout migrations, fresh installs, and ZIP creation via `BackupTask.forStartupUpgrade`.
- Added regression tests in `UpdateCheckerSelectionTest` covering `UpdateChecker.getAvailableUpdate(...)` and `DefaultConfig.shouldNotifyOpOfUpdates()` defaults.
