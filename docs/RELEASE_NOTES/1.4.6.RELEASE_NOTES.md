# BlockProt Reloaded 1.4.6 Release Notes

Welcome to BlockProt Reloaded 1.4.6. This release moves automatic operator/admin update notifications on join out of chat into the ActionBar above the hotbar, introduces the `notify_admins_on_join` child configuration option under `notify_op_of_updates` across all configuration UIs, ensures passive in-game update banners respect `notify_op_of_updates`, and preserves always-on console update logging for Minecraft 1.21.7 through 26.3 on Paper, Purpur, and Folia.

## Highlights

- **ActionBar Join Update Alerts**: Automatic on-join update alerts for operators and admins (`JoinEventListener` and `UpdateChecker.forJoinActionBar`) now display cleanly in the ActionBar via `TemporaryActionBar` (scheduled on the player's entity thread with `runAtEntityLater`) instead of sending multi-line chat messages on every join.
- **Child Configuration Toggle (`notify_admins_on_join`)**: Added `notify_admins_on_join: true` in `config.yml` as a child option under `notify_op_of_updates` so server administrators can disable join ActionBar notifications independently of general in-game update alerts.
- **Always-On Console Logging**: Server console update checks and warnings continue running regardless of whether `notify_op_of_updates` or `notify_admins_on_join` is disabled.
- **Full Menu & Dialog Parity**: Exposed `notify_admins_on_join` in Paper Dialogs (`AdminConfigNotificationsDialog`), Chest Inventory GUIs (`AdminConfigNotificationsInventory`), and Floodgate/Bedrock Forms (`BedrockAdminConfigForm`).

## Changelog

### Improved

- Added `UpdateChecker.forJoinActionBar(...)`, `UpdateChecker.actionBarOutdatedKey(...)`, and `UpdateChecker.buildActionBarUpdateComponent(...)` to render concise pastel-colored ActionBar alerts (`messages.update.actionbar_outdated`, `actionbar_outdated_hotfix`, `actionbar_outdated_dev`) when an update is available, without nagging on join when up to date or ahead.
- Kept full clickable download links and changelog summaries intact when running `/bp update` (`UpdateCommand`) or clicking the Update button in `/bp admin`.
- Added `DefaultConfig.shouldNotifyAdminsOnJoin()`, `isNotifyAdminsOnJoinSettingEnabled()`, and `setNotifyAdminsOnJoin(boolean)`, mirroring `owner_notifications` parent-child gating while keeping existing `config.yml` files untouched.
- Updated `AdminMenuDialog` and `AdminMenuInventory` so passive pending-update banners in `/bp admin` obey `notify_op_of_updates`.
- Added localized copy in `translations_en.yml`, `translations_es.yml`, `translations_de.yml`, and `translations_fr.yml` clarifying in-game update alerts vs. always-on console logging.

### Tests

- Extended `TranslatorTest` to validate `notify_op_of_updates` and `notify_admins_on_join` parent-child defaults, explicit overrides, and English/Spanish translation loading.
- Extended `UpdateCheckerSelectionTest` to validate ActionBar translation key selection across stable, hotfix, and `BEDev` channels as well as rendered ActionBar text.
