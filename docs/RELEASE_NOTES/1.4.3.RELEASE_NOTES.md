# BlockProt Reloaded 1.4.3 Release Notes

Welcome to BlockProt Reloaded 1.4.3. This release overhauls the update notification engine for hotfixes, expands block, container, fluid, fire, entity, and projectile protections, strengthens Folia region-thread safety and SQLite/cache reliability, refines staff tier inheritance and command gating, completes German and French translation parity (936/936 declared `TranslationKey` entries; 960/960 total keys), and consolidates GitHub Actions CI. It maintains the declared support range: Minecraft 1.21.7 through 26.3 on Paper, Purpur, and Folia.

## Highlights

- **Update Checker & Hotfix Detection Overhaul**: the update engine now follows HTTP 301 and 302 redirects, caches release data with a 30-minute TTL, identifies hotfix releases tagged on GitHub, guarantees console warnings at boot even with completion callbacks, and displays status messages in native MiniMessage styled with the pastel palette (`<#98FF98>`).
- **Dynamic Command & Menu Feature Gating**: subcommands, tab-completion entries, chest menus, and Paper Dialog buttons respect configuration toggles in `config.yml`. When `admin_tiers.enabled`, `disable_friend_functionality`, `world_expiry.enabled`, or `enable_session_log` disable a feature, the matching subcommands and buttons are hidden and guarded cleanly. Administrators with update permission keep `/bp update` access even when `use_menus` is enabled.
- **Expanded Block, Container, Environmental & Entity Protections**:
  - **Decorated Pots & Chiseled Bookshelves**: projectiles cannot shatter or trigger locked decorated pots, and chiseled bookshelves enforce per-slot `READ`/`WRITE` access permissions instead of allowing unauthorized slot edits.
  - **Fire, Fluids, Falling Blocks & Dispensers**: fire ignition/spread (`BlockIgniteEvent`, `BlockSpreadEvent`), water/lava flow (`BlockFromToEvent`), unauthorized bucket empty/fill or waterlogging, falling blocks landing on locked blocks, and dispenser redstone activation against protected containers are now blocked.
  - **Entities, Item Frames & Hoppers**: protected entities block damage, projectiles, and leashes; linked item frames fire `BlockAccessMenuEvent`; `InventoryPickupItemEvent` stops unauthorized hopper pickup siphoning; and `simplified_hopper_logic` preserves container siphon checks.
- **Folia Region Safety, SQLite Concurrency & Cache Bounds**: synchronized serialized WAL SQLite pooling and connection reuse in `AuditLogger`, non-blocking bounded TTL lookups in `HybridDatabase` and bounded Caffeine cleanup in `ProtectedBlockCache`, thread-safe state in `InventoryState` / `DialogState`, and proper Folia entity/region dispatch in `TownyIntegration`, `WorldExpiryTask`, `InactivityCleanupTask`, and `VillagerLocateTask`.
- **Staff Tiers & Permission Precedence**: `blockprot.user.admin.t2` now explicitly includes `blockprot.user.admin` (capped at T2 actions under `admin_tiers.enabled: true`), explicit permission negations override OP fallback consistently across commands and GUIs, and `plugin.yml` adds `Residence` and `GriefPrevention` to `softdepend`.
- **Offline Mode Optimization & Forward-Compatibility Prep**: offline-mode servers (`online-mode: false`) skip Mojang HTTP lookups in `CachedProfileService`, `BedrockBridge` strips handshake query strings during prefix detection, and `BlockFamilyParser` / `VersionCompat` safely ignore unknown future block materials without failing startup.
- **Complete German & French Translation Parity**: `translations_de.yml` and `translations_fr.yml` reach 100% parity (936/936 declared `TranslationKey` entries; 960/960 total YAML keys) alongside `translations_en.yml` and `translations_es.yml`.
- **Unified GitHub Actions CI & Test Coverage**: consolidated build, server smoke, and Mineflayer player tests into [blockprot.yml](https://github.com/Zaynr-Ecosystem/BlockProt-Reloaded/blob/main/.github/workflows/blockprot.yml) with job timeouts and JAR exclusion filters, added [translations.yml](https://github.com/Zaynr-Ecosystem/BlockProt-Reloaded/blob/main/.github/workflows/translations.yml) with 52 Python CI script tests, and expanded JUnit coverage to 88 tests (including `TranslatorTest` and `AuditAndRegressionTest`).

## Changelog

### Added

- Projectile, fire (`ignite` / `spread`), fluid (`BlockFromToEvent` / bucket empty & fill), falling block, dispenser redstone, and entity leash/projectile/damage protections across protected blocks and entities.
- Per-slot protection for `CHISELED_BOOKSHELF` (`READ` / `WRITE`) and projectile/interaction protection for `DECORATED_POT`.
- `BlockAccessMenuEvent` dispatch on linked item frames and `InventoryPickupItemEvent` guard on hopper item pickup.
- Dedicated `translations.yml` workflow, `.github/scripts/audit_translations.py`, 52 Python CI unit tests, and `AuditAndRegressionTest` regression tests.
- Defensive runtime resolution in `VersionCompat`, `BlockFamilyParser` (copper grate sub-family readiness), and handshake query-parameter stripping in `BedrockBridge`.
- `Residence` and `GriefPrevention` added to `softdepend` in `plugin.yml`.

### Changed

- Consolidated simulated player bot matrix tests from `player-tests.yml` into `.github/workflows/blockprot.yml`, added job `timeout-minutes` bounds, excluded `-javadoc`/`-sources` artifacts from smoke uploads, and standardized `plugins/*/logs/` artifact paths.
- Updated dependencies in `spigot/build.gradle.kts`: `com.github.ben-manes.caffeine:caffeine` to `3.3.1` and `com.mysql:mysql-connector-j` to `26.10.0`.
- Reworked `AuditLogger` SQLite handling with serialized WAL connection management and safe `/bp logs` query execution.
- Updated `blockprot.user.admin.t2` inheritance in `plugin.yml` and enforced explicit permission negation precedence over OP fallback in `AdminTierManager`.
- Dispatched `TownyIntegration` unclaim cleanup, `WorldExpiryTask`, `InactivityCleanupTask`, and `VillagerLocateTask` through Folia-compatible region and entity schedulers.
- Configured the updater `HttpClient` with `.followRedirects(HttpClient.Redirect.NORMAL)` and a 30-minute `latestVersion` cache TTL in `UpdateChecker`.
- Upgraded MiniMessage / legacy serialization in `ComponentMessages` and `UpdateChecker` to use the official pastel color palette (`<#98FF98>`, `<#F0E6A0>`, `<#7EC8E3>`, `<#FF6B6B>`, `<#B39DDB>`).

### Fixed

- Hotfix releases tagged on GitHub are recognized properly on stable servers and startup console warnings are always logged even when an `onComplete` callback is supplied.
- Container bypass parity enforced cleanly across `InventoryEventListener`, `InteractEventListener`, and `AdminUnlockCommand` / `/bp tiers` / `/bp lockables` (`/bp lockables` supports left-click live toggling and right-click copy token).
- Bounded `ProtectedBlockCache` and non-blocking `HybridDatabase` negative/TTL caches prevent main-thread or region-thread stalls during hopper and chunk operations.
- Stalled Mojang HTTP calls on offline-mode servers eliminated via `Bukkit.getOnlineMode()` gating.
- Synchronized `InventoryState` / `DialogState` access and `/bp logs` pagination safety fixes.
- Filled missing and null entries across `translations_de.yml` and `translations_fr.yml` and fixed generated edition description parity in `docs/READ_MEs/editions/`.

## Editions

BlockProt Reloaded covers Minecraft 1.21.7 through 26.3. **BlockProt Reloaded Legacy** (Minecraft 1.20.5 to 1.21.6) and **BlockProt Legacy** (Minecraft 1.18.2 to 1.20.4) have also received the applicable security, Folia, cache, and logic backports along with aligned CI workflows (note that new features such as `/bp logs` and Paper Dialogs remain exclusive to BlockProt Reloaded). See the [version guide](https://github.com/Zaynr-Ecosystem/BlockProt-Reloaded/blob/main/docs/READ_MEs/VERSION_GUIDE.md) for edition details.
