# BlockProt Reloaded 1.4.3 Release Notes

Welcome to BlockProt Reloaded 1.4.3. This release overhauls the update notification engine for hotfixes, adds dynamic feature gating to hide disabled subcommands and GUI buttons, aligns container bypass permissions between interact and inventory open listeners, optimizes offline-mode profile resolution, fully completes German and French translations (960/960 keys), and consolidates GitHub Actions pipelines into a single unified workflow. It maintains the same support range: Minecraft 1.21.7 through 26.3 on Paper, Purpur, and Folia.

## Highlights

- **Update Checker & Hotfix Detection Overhaul**: the update engine now follows HTTP 301 and 302 redirects (such as repository migration to the Zaynr-Ecosystem organization), caches release data with a 30-minute time-to-live to prevent stale results, correctly identifies hotfix releases tagged on GitHub, guarantees console warnings at boot even when asynchronous completion callbacks are passed, and displays the up-to-date notification in native MiniMessage styled with the official pastel mint palette (`<#98FF98>`).
- **Dynamic Command & Menu Feature Gating**: subcommands, tab-completion entries, chest menus, and Paper Dialog buttons now respect configuration toggles in `config.yml`. When `admin_tiers.enabled` is false, `/bp tiers` is removed from tab-completion, rejected as an unknown command, and omitted from admin menus and dialogs. Similar gating applies to `/bp friends` when `disable_friend_functionality` is true, world expiry items, and session logs. Administrators with update permission can now run `/bp update` even when menu mode is enabled.
- **Container Bypass Security Parity**: `InventoryEventListener` now verifies `AdminTierManager.hasPermission(player, AdminAction.CONTAINER_BYPASS)` across container, entity, and block access events, matching `InteractEventListener`. Staff members with granular container bypass permissions can inspect containers without being kicked out by `InventoryOpenEvent`.
- **Offline Mode Optimization**: servers running in offline mode (`online-mode: false`, including Velocity and BungeeCord proxy networks) now bypass external Mojang HTTP API lookups in `CachedProfileService`, eliminating network timeout stalls and preventing online Mojang UUIDs from conflicting with server-local offline UUIDs.
- **Complete German and French Translation Parity**: all 960 canonical keys in `translations_de.yml` and `translations_fr.yml` are now fully translated with zero null placeholders, providing complete coverage for Paper Dialogs, admin tiers, world expiry, container inspection, and raid alerts.
- **Unified GitHub Actions CI Pipeline**: consolidated the build, server smoke, and Mineflayer player bot matrix tests into a single all-in-one workflow (`blockprot.yml`), eliminating redundant duplicate workflow triggers on push. Added a dedicated `translations.yml` workflow for strict language validation.

## Changelog

### Added

- A dedicated `translations.yml` workflow and Python auditing tool (`.github/scripts/audit_translations.py`) with 52 unit tests to verify 100% key parity and placeholder integrity across Tier-1 languages.
- MiniMessage parsing with pastel mint styling (`<#98FF98>`) for the up-to-date status message.
- Granular permission check `AdminAction.UPDATE` allowing tier administrators to execute `/bp update` when `use_menus` is enabled and to receive join notifications.
- Defensive configuration inspection in `Translator` and `BlockProt.getDefaultConfigOrNull()` for headless environments and unit tests.

### Changed

- Consolidated simulated player bot matrix tests from the separate `player-tests.yml` directly into `.github/workflows/blockprot.yml`.
- Configured the updater `HttpClient` with `.followRedirects(HttpClient.Redirect.NORMAL)`.
- Added a 30-minute cache TTL (`CACHE_TTL_MILLIS`) to in-memory `latestVersion` in `UpdateChecker`.
- Updated dependencies: `WorldGuard` to `7.0.21`, `Caffeine` to `3.3.1`, `ViaVersion` to `5.12.2`, and `mysql-connector-j` to `26.10.0`.
- Upgraded internal legacy serializers in `ComponentMessages` and `UpdateChecker` to preserve Adventure hex RGB color codes.

### Fixed

- Hotfixes tagged on GitHub are now recognized by `UpdateChecker.selectBest()` on stable channel servers.
- The startup console warning for outdated versions is no longer bypassed when an `onComplete` callback is passed.
- Missing and null entries in `translations_de.yml` and `translations_fr.yml` (612 keys) replaced with authentic German and French translations.
- Disabled features (`admin_tiers.enabled: false`, `disable_friend_functionality: true`, `world_expiry.enabled: false`, `enable_session_log: false`) no longer leak into `/bp` tab-completion, CLI execution, chest inventories, or Paper Dialogs.
- Staff with `CONTAINER_BYPASS` tier permission can now access protected containers without being cancelled by `InventoryEventListener`.
- Stalled Mojang HTTP calls on offline servers eliminated by checking `Bukkit.getOnlineMode()` before falling back to external API repositories.
- Corrected fallback download URL in `UpdateDialog` to point to the canonical Zaynr-Ecosystem release path.

## Editions

BlockProt Reloaded covers Minecraft 1.21.7 and newer. BlockProt Reloaded Legacy (Minecraft 1.20.5 to 1.21.6) and BlockProt Legacy (Minecraft 1.18.2 to 1.20.4) are unchanged by this release. The [version guide](https://github.com/Zaynr-Ecosystem/BlockProt-Reloaded/blob/main/docs/READ_MEs/VERSION_GUIDE.md) explains which one to download and how to move between them.
