# BlockProt Reloaded Legacy 1.4.0.2 Release Notes

Welcome to BlockProt Reloaded Legacy 1.4.0.2, the maintenance and stability release for Minecraft 1.20.5 through 1.21.6 on Paper, Purpur, and Folia (Java 21+). This release ships all accumulated security, Folia, cache, and update-checker fixes so legacy servers stay current on bug fixes and reliability.

## Highlights

- **Reliable Update Detection**: `UpdateChecker` now requests `?per_page=100`, follows HTTP redirects cleanly, refreshes cached release state every 30 minutes instead of only once per restart, and detects hotfix releases even when marked pre-release on GitHub.
- **Operator Update Alerts Enabled by Default**: `notify_op_of_updates` now defaults to `true` for new installs and missing config keys, update messages remind admins that even 1 build behind matters, and `/bp admin` highlights available updates on the Update button.
- **Included Stability & Security Backports**: ships the 1.4.0.1 branch backports (decorated pot projectile protection, chiseled bookshelf write/container checks, fire/fluid/falling-block/dispenser/entity guards, Folia region dispatch fixes, bounded `ProtectedBlockCache` / `HybridDatabase` caching, SQLite WAL locking, staff tier inheritance, and transfer statistics accuracy).

## Changelog

### Fixed

- Updated `Edition`, `BlockProtConsole`, and `BlockProt` so running on any unsupported Minecraft version (below `1.20.5` or above `1.21.6`) prints a prominent red console banner with the recommended edition (`BlockProt Legacy` or `BlockProt Reloaded`) and Modrinth link and disables only the plugin cleanly without stopping the server.
- Updated `UpdateChecker` to fetch `?per_page=100`, enable `HttpClient.Redirect.NORMAL`, expire the cached release lookup after 30 minutes (`CACHE_TTL_MILLIS`), and allow hotfixes tagged as pre-release on GitHub (`selectBest`).
- Enabled `notify_op_of_updates: true` by default in `config.yml` and `DefaultConfig.shouldNotifyOpOfUpdates()` while preserving existing user configs.
- Added `UpdateChecker.getAvailableUpdate(...)` and surfaced available update details inside `AdminMenuInventory` (`SLOT_UPDATE`) with hex-safe lore serialization.
- Clarified update alert strings in `translations_en.yml` and `translations_es.yml` using the pastel coral hex palette (`<#FF6B6B>`).
- Synchronized platform listing descriptions (`MODR_HANG_README`) across editions.

## Editions

BlockProt Reloaded Legacy covers Minecraft 1.20.5 through 1.21.6. See the [version guide](https://github.com/Zaynr-Ecosystem/BlockProt-Reloaded/blob/main/docs/READ_MEs/VERSION_GUIDE.md) for BlockProt Reloaded (1.21.7+) and BlockProt Legacy (1.18.2 - 1.20.4).
